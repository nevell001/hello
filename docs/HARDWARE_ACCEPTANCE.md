## 1. 准备与配置检查

- [ ] 应用可登录、数据库正常
- [ ] 网络打印机已在应用内注册：`POST /api/printers/add`（参数 name/host/port/timeout/paperWidth），
      `GET /api/printers` 可见该设备且状态正常
- [ ] 纸张规格：注册时的 paperWidth 与实际热敏纸一致（58mm / 80mm）
- [ ] API 已启用（打印接口依赖 `api.enabled=true`）：`POST /api/printers/{id}/test` 可出测试页
- [ ] Logo（如启用）：设备配置的 logoPath 指向的文件存在，PNG/JPG/GIF 格式

> ⚠️ 已知现状（v2.6.0）：`config/printer.properties` 不被运行时读取（参考模板）；设置页的打印开关/打印机名称/纸张为预留字段，
> 不参与实际打印；当前唯一可物理出票的路径是 REST API 注册的网络 ESC/POS 打印机。现场配置请走第 9 节入口，避免只改模板不生效。

## 2. 打印机验收

### 2.1 测试页与基础输出

- [ ] 测试页可打印：内容含设备名称 / ID / 类型、分隔线，中文不乱码（API：`POST /api/printers/{id}/test`）
- [ ] 出纸与切纸：每张小票打印后设备按 ESC/POS 切纸指令出纸（半切/全切以设备侧设置为准）
- [ ] 条码/二维码：当前版本运行时未接线（`thermal.print.barcode/qrcode` 为预留字段）——门店小票必须带条码时，需先确认改造方案
- [ ] 预览（如启用）：预览内容与实打结果一致

### 2.2 业务单据（每类各打一张，核对内容）

> 销售/交接班等小票走 `PrinterManager`，需已注册并连接网络打印机；退货单据走 `ReceiptPrinter` 生成 `receipts/` 文本文件并提示路径（不向操作系统提交打印任务）。

- [ ] 销售小票：商品明细 / 数量 / 折扣 / 应收 / 实收 / 找零 / 会员信息 / 门店与收银员
- [ ] 退货小票：退货明细与退款金额正确
- [ ] 交接班小票：开班/交班金额与系统一致
- [ ] 入库单据：入库商品与数量正确
- [ ] 会员收据：充值/消费前后余额正确
- [ ] 报表：盘点 / 销售统计 / 利润 / 采购，列宽与合计正确

### 2.3 异常路径

- [ ] 缺纸：应用给出提示、不崩溃；换纸后下一单恢复正常
- [ ] 打印机关机/离线：任务失败有提示，收银流程不中断（打印队列已实现失败不阻塞）
- [ ] 恢复：打印机重启后无需重启应用即可继续打印
- [ ] 大单：50 行以上商品小票不截断、不乱码、耗时正常

## 3. 扫码枪验收（USB-HID 模拟键盘）

- [ ] 普通条码：收银页搜索框扫码自动加购，数量累加正确
- [ ] 精确命中：触屏版唯一结果自动加购
- [ ] 提示音：成功 / 未找到 / 错误三种声音区分正确
- [ ] 未命中：不误加购，保留输入并提示
- [ ] 超长条码：超过 128 字符被拒绝并告警，不影响后续扫码
- [ ] 快速连扫：连续扫码不串行、不丢失、不重复加购（有去重保护）
- [ ] 焦点切换：焦点在会员手机号输入框时，扫码进入该字段而非搜索框
- [ ] 特殊字符：Code128 等含大小写/特殊字符的条码识别正确（`normalizeScanData` 归一化）
- [ ] 拔插重连：扫码枪拔掉重插后无需重启应用
- [ ] 无焦点目标：扫码被丢弃并有告警日志，应用不崩溃

## 9. 自测入口速查

| 入口 | 路径/操作 | 说明 |
| --- | --- | --- |
| 设置页 | 设置 → 打印 | 预留字段（当前不参与实际打印）；门店名称/收银员等设置会生效 |
| API 打印机列表 | `GET /api/printers` | 查看已注册设备与状态 |
| API 添加网络打印机 | `POST /api/printers/add` | 网络 ESC/POS 打印机的注册入口 |
| API 测试打印 | `POST /api/printers/{id}/test` | 打印测试页 |
| API 钱箱 | `POST /api/printers/{id}/cashdrawer` | 开箱指令 |
| 扫码枪 | 收银页直接扫码 | 无独立自测按钮，以实际扫码流程验证 |

## 附注：当前支持的硬件范围

- 物理出票：仅网络 ESC/POS 打印机（REST API 注册，TCP 9100）能实际打印；桌面设置页打印字段与 `config/printer.properties` 均未接线。
- 退货单据：`ReceiptPrinter` 生成 `receipts/` 文本文件并提示路径，不向操作系统提交打印任务。
- 扫码枪：USB-HID 模拟键盘模式，依赖窗口焦点；无串口/蓝牙扫码枪的生产注册路径；无独立配置/自测入口（maxScanLength 默认 128）。
- `PrinterDeviceType` 枚举含 USB 热敏 / 串口 / 蓝牙类型，但当前运行时没有对应的注册实现；门店若使用这些类型，需在验收前确认兼容方案。
