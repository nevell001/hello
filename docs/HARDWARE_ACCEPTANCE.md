## 1. 准备与配置检查

- [ ] 设置 → 打印：勾选“启用打印”，打印机名称与 Windows/系统默认打印机一致
- [ ] 纸张规格：设置页选择的 58mm / 80mm 与实物热敏纸一致
- [ ] Logo（如启用）：`logo.path` 指向的文件存在，PNG/JPG/GIF 格式
- [ ] 网络打印机（如使用）：IP / 端口（默认 9100）/ 超时（默认 5000ms）已按设备填写
- [ ] 切纸与条码：`thermal.cut.paper`（1 全切 / 2 半切 / 0 不切）、`thermal.print.barcode/qrcode` 按需配置
- [ ] API 自测入口（如启用 API）：`api.enabled=true` 后可调用打印机接口（见第 9 节）

## 2. 打印机验收

### 2.1 测试页与基础输出

- [ ] 测试页可打印：内容含设备名称 / ID / 类型、分隔线，中文不乱码（API：`POST /api/printers/{id}/test`）
- [ ] 自动切纸：每张小票打印后按配置切纸（全切/半切）；关闭切纸时可手动撕纸
- [ ] 条码/二维码：开启后小票上的条码可被扫码枪或手机识别
- [ ] 预览/落盘（可选）：`print.preview=true` 控制台预览、`print.to.file=true` 输出文件内容正确

### 2.2 业务单据（每类各打一张，核对内容）

- [ ] 销售小票：商品明细 / 数量 / 折扣 / 应收 / 实收 / 找零 / 会员信息 / 门店与收银员
- [ ] 退货小票：退货明细与退款金额正确
- [ ] 交接班小票：开班/交班金额与系统一致
- [ ] 入库单据：入库商品与数量正确
- [ ] 会员收据：充值/消费前后余额正确
- [ ] 报表：盘点 / 销售统计 / 利润 / 采购，列宽与合计正确

### 2.3 异常路径

- [ ] 缺纸：应用给出提示、不崩溃；换纸后下一单恢复正常
- [ ] 打印机关机/离线：任务失败有提示，收银流程不中断（打印队列已实现失败不阻塞）
- [ ] 恢复：打印机重启后无需重启应用即可继续打印
- [ ] 大单：50 行以上商品小票不截断、不乱码、耗时正常

## 3. 扫码枪验收（USB-HID 模拟键盘）

- [ ] 普通条码：收银页搜索框扫码自动加购，数量累加正确
- [ ] 精确命中：触屏版唯一结果自动加购
- [ ] 提示音：成功 / 未找到 / 错误三种声音区分正确
- [ ] 未命中：不误加购，保留输入并提示
- [ ] 超长条码：超过 128 字符被拒绝并告警，不影响后续扫码
- [ ] 快速连扫：连续扫码不串行、不丢失、不重复加购（有去重保护）
- [ ] 焦点切换：焦点在会员手机号输入框时，扫码进入该字段而非搜索框
- [ ] 特殊字符：Code128 等含大小写/特殊字符的条码识别正确（`normalizeScanData` 归一化）
- [ ] 拔插重连：扫码枪拔掉重插后无需重启应用
- [ ] 无焦点目标：扫码被丢弃并有告警日志，应用不崩溃

## 4. 钱箱（如启用）

- [ ] 结账完成后钱箱自动弹开（API：`POST /api/printers/{id}/cashdrawer`）
- [ ] 钱箱未接/故障：有提示且不影响收银

- [ ] 分辨率适配（≥1024×768）无按钮遮挡

## 9. 自测入口速查

| 入口 | 路径/操作 | 说明 |
| --- | --- | --- |
| 设置页 | 设置 → 打印 | 启用打印、默认打印机、纸张、Logo |
| API 打印机列表 | `GET /api/printers` | 查看已注册设备与状态 |
| API 添加网络打印机 | `POST /api/printers/add` | 网络 ESC/POS 打印机的注册入口 |
| API 测试打印 | `POST /api/printers/{id}/test` | 打印测试页 |
| API 钱箱 | `POST /api/printers/{id}/cashdrawer` | 开箱指令 |
| 扫码枪 | 收银页直接扫码 | 无独立自测按钮，以实际扫码流程验证 |

## 附注：当前支持的硬件范围

- 打印机：Windows/系统默认打印机（设置页配置）与网络 ESC/POS 打印机（API 注册，TCP 9100）。
- 扫码枪：USB-HID 模拟键盘模式，依赖窗口焦点；无串口/蓝牙扫码枪的生产注册路径。
- `PrinterDeviceType` 枚举含 USB 热敏 / 串口 / 蓝牙类型，但当前运行时没有对应的注册实现；门店若使用这些类型，需在验收前确认兼容方案。
